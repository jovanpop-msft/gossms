🚀 goSSMS v0.1.0 is out!

goSSMS is a free, open source, terminal-based SQL Server management tool for macOS, Linux and Windows. The goal is functional parity with SQL Server Management Studio, so SQL developers on macOS and Linux get the tooling they have been missing.

In this article you'll find:
• What goSSMS is and what it can do today
• Install steps for Homebrew, APT and direct download
• What to expect from Windows Defender on first run
• Links to the GitHub repo, releases, wiki screenshots and Discord

Read on, give it a try, and star and watch the repo on GitHub to follow new releases. Feedback and contributions are always welcome!
