# **🚀 goSSMS v0.1.0**
A hardening release: safer backups, safer files.

## ✨ New
- Windows on ARM build
- Backup checks: unique names, overwrite prompt, types greyed with reason
- Database menu state toggle, file shrink/grow
- Change Tracking columns, login policy, role ratings
- Messages pane jumps to the error line

## 🔧 Fixes
- Results To File no longer overwrites with partial output
- CSV NULL rows, copy from an empty grid
- Atomic config writes, corrupt config kept
- Restore verifies the chosen set
- AG, Query Store, containment validation

## ⚡ Changes
- `gosmo` v0.1.0
